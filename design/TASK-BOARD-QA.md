`python3 scripts/verify-cli.py` 使用独立数据库，验证新旧 CLI 命令、JSON 输出、幂等冲突、非法参数、部分字段更新、完成时间、清除日期、转换重试、搜索和导出。

`zsh scripts/build.sh` 生成 release 应用和 CLI，并完成 ad-hoc 签名验证。未编辑用户已有的图标及构建脚本修改。

## 验证限制

鼠标自动化可以启动原生拖拽会话，但未得到跨列放下后的成功状态更新；因此鼠标拖拽端到端验收仍未通过，不能以模型层拖放测试替代。月历版本已将此路径替换为统一的 AppKit 私有任务类型接收器与原始快照校验，状态菜单已通过原生验收。拖放仍需继续用实际鼠标检查，最新结果见 [任务月历验收](CALENDAR-QA.md)。

中文输入已验证粘贴多行文字与 marked-text 单元测试，未完成真实拼音候选窗的人工输入验收。本次未调用真实 AI provider；验证覆盖结构化 action 解析、写入与原子性。

当前查询一次读取匹配任务以计算列计数，界面只渲染已完成的前 20 条；非常大的任务归档可后续将计数和已完成分页移到独立 SQL 查询。旧完成时间由旧 updatedAt 近似回填。应用与 CLI 应一起更新，不支持旧二进制与新数据结构混用。

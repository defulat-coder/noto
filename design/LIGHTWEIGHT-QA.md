# 轻量化交互验收

2026-09-09。本次覆盖并替代旧月历的格内摘要、116pt 格高、详情自动滚动和宽屏侧栏布局。

## 变化

- 六周日期导航每格 36pt，只有日期、未完成数量或完成提示；选中日期更新下面的列表，不滚走月历。
- 当天列表去掉卡片背景和重复日期，普通任务无空星标；已完成默认折叠。列表独立滚动，月历保持可见。
- 搜索直接展示全部日期结果和日期标签，清空后恢复之前的日期选择。
- 新建任务突出文字，日期与重要标记可选。状态在编辑时设置，看板列预设保留提示。
- 日期入口：今天、明天、选择日期、清除。自选日期确认前不改草稿字段；编辑笔记模式里的任务也复用此入口。
- 笔记新增可见编写入口，⌘↵ 直接保存，AI 为次级按钮；AI 运行期间可保存笔记。
- 更多菜单保留弱化显示，确保原生键盘与辅助功能入口。原先尝试聚焦时显隐的版本造成 SwiftUI 原生菜单更新循环，已移除该焦点绑定并实测切日、搜索和新建恢复正常。

## 验证

- `swift test`：21 项通过，包括本地保存不创建对话、AI 忙时仍可保存笔记，以及原有日期、任务、草稿、冲突、查询测试。
- release 构建与签名验证通过，`git diff --check` 通过。
- 独立 QA 应用和数据库：620pt 深色窗口同屏显示日期导航和当天任务，日期切换不跳走月历。
- 已完成 22 条默认折叠，展开可以访问全部记录，滚动只作用于列表。
- 搜索无日期任务时隐藏月历、显示「未安排」标签；清空搜索恢复之前选中日期。
- 新建表单不显示默认状态。清除日期、切重要、⌘↵ 保存后数据库为 todo / due NULL / priority important。
- 日期弹层包含四个操作；自选日期展开原生日期控件，明天快捷项正确设置日期。
- 笔记输入后 ⌘↵ 保存到数据库为 note，hasConversation 为 false，没有触发 AI。
- 浅色最终月历截图未完成：测试期间用户正在操作窗口，已停止 QA 应用避免干扰。本次不据此声称完成浅色月历全流程验证。

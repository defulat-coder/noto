## 已修复

| 路径 | 问题 | 改动 |
| --- | --- | --- |
| 启动 | 主线程打开数据库、执行迁移和首次查询 | 正常启动在后台打开数据库，显示加载状态；预览小样本保持简单 |
| 搜索与分页 | 每次输入同步查询；刷新同时读取时间线和整个任务库 | 200ms 搜索防抖；后台查询当前视图；请求代次与取消检查防止旧搜索、旧分页覆盖新结果 |
| 数据库并发 | 单连接使读取与写入串行等待 | 磁盘数据库采用 GRDB DatabasePool/WAL；data_version 固定从写连接读取，保持跨进程检测正确 |
| 锁竞争 | 桌面保存遇到其他写进程时可阻塞 5 秒 | 桌面锁等待限制为 100ms，失败沿用保留草稿与错误提示；CLI 仍保留 5 秒重试窗口 |
| 日历/看板 | body 多处访问派生属性时反复过滤、排序、分组 | 缓存任务筛选、列分组、日历排序和日期分组；任务或重要性筛选变化时失效 |
| 时间线 | 每次访问重新分组，逐条创建 DateFormatter；同一天的记录全部构建 | 缓存分组，记录/编辑对象/时区变化时失效；日期使用日历组件；同日记录使用 LazyVStack |
| 任务文本与拖拽 | 任意模型通知都会重新编码 Entry、创建富文本并测量 | 仅 Entry/显示参数变化时更新；按宽度复用测量结果；编辑回调始终更新 |
| 对话 | 输入草稿也会重新解析已显示的 Markdown | 独立文本视图按消息内容异步解析；失效任务不发布旧结果 |
| 空闲轮询 | 后台仍周期唤醒；未释放 timer | 非活动应用暂停轮询，激活时检查；设置 timer tolerance，并在析构时清理 |
| CLI | 列笔记和更新一条笔记先解码全库 | SQL 筛选笔记；单条更新在事务内查主键并检查类型 |
| 导出 | 每个对话一个查询，且多次读可能来自不同数据库状态 | 一个一致性快照中读取两张表，再按 entryID 分组 |
| AI/撤销 | 对每条 action/undo 反复线性查找完整上下文 | 一次构建 ID 查找表，保留冲突校验和事务回滚 |
| AI 进程 | 忽略 SIGTERM 时取消无法结束等待；输出文件无限制读入内存 | 取消后 1 秒仍运行则终止该进程；输出读取上限 2MB，错误诊断上限 64KB |

## 可复现基准

本机 ARM64、macOS 26.5.2。以下是合成数据的本机测量，不等同于帧率或所有设备的响应保证。

`swift test --filter PerformanceTests.testLargeCalendarAndTimelineReadCost`：10,000 条任务、2,000 条时间线记录，20 次读取日历/时间线分组，包含首次计算。Debug 同一测试改动前 **3659.9ms**，改动后多轮 **63–70ms**，最后一轮 **68.7ms**，减少约 **98%**。该结果衡量派生数据计算，不包含窗口绘制。

`python3 scripts/verify-performance.py`：Release 可执行文件；临时数据库含 20,000 条记录，其中 10,000 条任务、1,000 个对话、2,000 条消息。每项运行三次取中位数，包含进程启动、数据库读取、JSON 输出和 Python 解码。

| 操作 | 中位数 |
| --- | ---: |
| 列出全部 10,000 条笔记 | 128.5ms |
| 列出全部 10,000 条任务 | 152.5ms |
| 搜索对话正文，返回 1,000 条 | 52.0ms |
| 更新单条笔记 | 13.3ms |
| 导出全部记录及对话 | 284.6ms |

该脚本仅创建临时库，默认删除；`--keep-fixture` 可保留并输出路径供原生界面压测。

## 仍需明确的规模边界

- 看板/日历仍读取全部匹配任务，以维持完整计数、日期分布与 AI 上下文；已完成列的 20 条限制只限制显示。十万级归档或大量长文本时，应把任务分页、计数与日历聚合下推到 SQL。
- 搜索保留现有任意子串（含中文、日期和对话）语义，仍是线性扫描。后台查询和防抖保证输入不执行扫描，但不降低查询本身的大数据复杂度；不能用普通分词全文索引直接替代而不改变匹配行为。
- 单条写入与打开一段对话仍为同步小操作。100ms 只限制 SQLite 锁等待，不限制异常慢磁盘、超长历史读取或系统 fsync；若部署环境出现这类实测瓶颈，应进一步将写入/对话读取改成异步状态流程。
- 取消会丢弃过时查询的结果；已经执行的同步 SQL 可以继续在后台完成。当前没有按查询强制中断 SQLite，也没有更换整个 ObservableObject 架构。
- 本轮未做 Instruments 帧时间分布、长时间滚动泄漏测试或真实网络 AI 延迟比较，不宣称已证明全场景 60/120fps。

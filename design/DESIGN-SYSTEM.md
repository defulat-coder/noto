# Noto 设计规范

版本：2026-09-09 · 范围：原生 macOS 14+ 全部现有界面与功能。

## 产品目标

一个随手记录、回看和整理想法的本地笔记本。默认专注阅读，输入按需出现；记录、待办、AI 是同一份内容的不同处理方式。保留单窗口、轻量日期导航、右侧对话、单项 AI 设置的产品结构。

依据：项目现有视觉稿 `reference.png`、`native-polish-after.jpg` 与实际运行界面；`.agents/skills/emil-design-eng/SKILL.md`。将设计原则用于 SwiftUI/AppKit，不照搬 Web 技术实现。

## 视觉基础

| 项目 | 规范 |
| --- | --- |
| 字体 | macOS 系统字体；中文由系统回退。正文 15pt，输入 16pt，标题 17pt/semibold，分组与操作 12–13pt，时间 11pt |
| 正文 | 行间距 4pt；允许多行和复制；长内容不挤压到单字列 |
| 色彩 | 背景 textBackgroundColor；输入 controlBackgroundColor；正文 primary；说明 secondary；强调 accentColor；错误 red；不强制明暗模式 |
| 层级 | 留白、字体和细线区分区域；不为每条记录增加卡片；对话用轻背景区分 |
| 间距 | 基础 4pt，常用 8/12/16/24/32/48；输入内边距 16，表单 28，内容边距随窗口缩放 |
| 圆角 | 输入 12，行 hover 8，轻按钮 6；细边框 0.5pt |
| 图标 | SF Symbols，12–16pt；图标按钮命中区至少 28×28pt；重要操作附帮助文字与辅助功能名称 |
| 阅读宽度 | 正文最大 620pt；主区域自然居中。打开对话后合理收紧边距，不强制增大窗口最小宽度 |
| 日期导航 | 折叠 88pt、展开 180pt；紧凑窗口展开宽度收为 144pt；选中使用 accent 与形状/字重共同区分 |
| 对话 | 宽窗口分栏，窄窗口独立占据内容区；关闭回到记录；不因侧栏出现让正文被裁切 |

## 交互与动效

Emil 的首要原则是先决定是否需要动画。输入、搜索、列表更新、快捷键操作立即执行；不添加逐条入场、滚动跟随或布局弹跳。鼠标展开日期侧栏可以使用 180ms ease-out；减少动态效果时关闭。按钮按下即时提供轻微颜色/缩放反馈，键盘激活不执行缩放动画。系统弹窗、日期选择和焦点行为优先使用平台实现。

所有控件覆盖默认、悬停、按下、禁用、键盘焦点。按钮禁用时说明通过上下文可理解：空输入不能发送；AI 忙碌时保留停止入口。空状态说明下一步，失败保留原输入并给出重试或关闭入口。错误不只用颜色传达。

## 页面与功能设计

| 页面/区域 | 功能与设计 | 必须覆盖的状态 |
| --- | --- | --- |
| 按需输入 | 双击阅读区空白就近唤起，⌘N 顶部唤起；回车换行、⌘ 回车 AI、⌘⇧ 回车待办；显式小记/待办/发送给 AI 操作；Esc/外点收起保留草稿 | 空白、输入中、长文本、中文输入法组合、保存成功/失败、AI 运行 |
| 历史列表 | 日期分组；正文与元信息分行；待办复选框；编辑与对话按钮固定可发现；右键复制和编辑 | 空、普通笔记、长笔记、待办打开/完成、日期到期/逾期、带对话、分页 |
| 日期导航 | 折叠短横线、展开日期；点击跳转，正文滚动同步选中；更早记录有明确加载入口 | 无记录禁用切换、展开/收起、选中、长历史 |
| 搜索 | 原生 NSSearchField；⌘K 聚焦；即时查询全部历史与对话；清空退出；展示已加载数量，有更多时不伪装为总数 | 有结果、无结果、长查询、清空、Escape |
| 操作反馈 | 固定在主阅读区底部，不随列表滚走；成功带勾，失败带警示；撤销与关闭可达，不自动消失以免错过 | 保存、完成、编辑、撤销、冲突/数据库错误 |
| 原位编辑 | 双击正文替换为编辑器；⌘ 回车保存、Esc 取消；脏草稿阻止切换；待办沿用日期控件；空文本禁用保存；错误保留草稿；对话记录注明历史不变 | 笔记/待办、无日期/有日期、取消/保存、无效输入、失败 |
| AI 对话 | 角色+内容的阅读流；选中记录明确标记；执行过程折叠；状态准确区分运行、失败、待回复、已保存与未发送草稿 | 多轮、长回复、执行展开、失败、停止、重试、草稿切换、重新打开 |
| 对话输入 | 圆角输入区；回车换行、⌘ 回车发送；忙碌时可写草稿并停止；上一轮未完成时先重试，避免连续悬空问题 | 空/输入/长文本、运行、失败恢复 |
| 设置 | 单个 AI CLI 选择项；说明使用本机登录，以及修改对下一轮生效；完成/Escape 关闭 | 所有现有 provider、持久化、键盘操作 |
| 应用菜单 | ⌘Z 撤销文本、⌘⌥Z 重做文本、⌘⇧Z 撤销记录；⌘N 顶部唤起输入、⌘K 搜索 | 可用/禁用、正确焦点 |
| 本地 CLI | 保留数据命令、JSON、共享数据库、导出、doctor 与 AI adapter 契约 | 核心回归、GUI/CLI 数据同步、错误无部分写入 |

## 设计评审

| Before | After | Why |
| --- | --- | --- |
| 操作结果在长列表底部 | 阅读区固定反馈栏 | 用户立即知道操作是否完成，并能撤销 |
| 正文、到期、时间、编辑同行 | 正文独占阅读宽度，元信息另起一行 | 長文本与窄窗口仍可读 |
| 对话打开触发 280ms 全局布局动画 | 快捷键和对话更新即时；仅鼠标低频动作短过渡 | 高频操作不等待，避免文本在重排中抖动 |
| 日期手填 YYYY-MM-DD | 开关 + 原生 DatePicker | 预防格式错误，保留无日期状态 |
| 对话标题只根据草稿显示已保存 | 按运行/失败/待回复/草稿/已保存显示 | 不混淆回复状态与草稿持久化 |
| AI 和待办依赖快捷键/右键发现 | 输入下方明确轻操作 | 新用户可发现，熟练用户仍用快捷键 |
| 打开对话提高窗口最小宽到 960 | 根据可用宽度选择分栏或对话单栏 | 紧凑窗口不被强制放大 |

## 验收原则

先 build/test，再用隔离数据库操作原生应用；不能用编译成功替代视觉检查。检验主列表、日期、搜索、编辑、设置、对话的真实操作和截图；核对数据库中的记录与对话。AI 成功验证只能来自真实 CLI；离线演示内容只用于布局，明确标记。外部 provider 限制、未执行的检查必须如实记录。

## 按需输入状态契约（2026-09-09）

浮层宽度最高 480pt，随阅读区缩小，距离边缘至少 16pt；长内容在原生输入区滚动。位置依据阅读区坐标与实际高度限制，不覆盖顶栏。正文、按钮、日期导航、复选框、滚动条、对话区域排除空白双击。再次唤起或移动使用同一份新建草稿，不影响按创建时间排序。

新建、续聊、编辑使用同一原生输入外观，按用途调用各自提交入口，各自持有草稿。回车由原生文本系统处理换行和输入法选词，⌘ 回车只走一次提交。新建保存失败不关闭；AI 失败保留已存问题并在对话中重试。原位编辑保留 ID、创建时间、类型、完成状态和截止日期，保存支持记录撤销；外部更新冲突时不覆盖。

具体状态验收见 [双击交互交付](DOUBLE-CLICK-QA.md)。草稿不跨应用退出恢复。

## 任务看板（2026-09-09）

顶栏笔记 / 任务切换，任务视图不使用日期侧栏，切换清空搜索。任务三列为待开始、进行中、已完成，优先级只用普通 / 重要星标。卡片使用轻背景、细边框和四行正文，避免状态大色块。列计数反映当前筛选的全部匹配任务；已完成每次显示更多 20 条。

任务模式 ⌘N 打开任务录入，⌘↵ 保存，Esc 取消。点击卡片打开编辑浮层，状态菜单、星标和日期均可直接操作；脏草稿阻止隐式关闭或切换。笔记转换保留 ID 和历史对话，反馈提供撤销和在看板查看。窄窗口横向滚动，列宽至少 260pt。更完整的验收与限制见 [任务看板验收](TASK-BOARD-QA.md)。

## 任务月历与视图入口

顶栏以单个 28pt SF Symbol 作为视图菜单入口：`text.alignleft`、`rectangle.split.3x1`、`calendar`。菜单内显示名称、当前勾选和快捷键，收起后不显示文字及箭头；使用浅悬停背景和辅助功能标签。任务工具使用加号与星标。

月历采用本地 Gregorian 日期、周一起始、七列六行；日期格使用细边框，今天以小圆点强调，选中日期用浅底色。摘要最多三条，更多数量跳转完整列表。内容宽度达到 980pt 时详情置右、宽 300pt，否则放在月历下面并在选中时滚到详情；620pt 保持七列。完成任务使用勾选和弱化文字，未安排任务始终可从收纳盒访问。

拖动只接受应用内部专用任务类型。AppKit 接收器负责整个日期格、列和收纳盒，高亮使用原生图层，避免拖动期间重建 SwiftUI 内容。原始快照交给共享事务更新接口；日期和状态各自部分更新。

## 2026-09-09 轻量化修订（覆盖上面的月历布局）

月历格高 36pt，仅显示日期、待完成数量或淡勾，去掉任务摘要与格子常驻边框。月历保持在列表上方，最大宽度 620pt；下面独立滚动当天任务。已完成默认折叠。任务行去掉卡片边框与同一天重复日期，普通任务无空星标。更多菜单以弱化样式保留原生键盘入口。搜索时隐藏月历并展示所有日期结果。

任务创建只显示文字、日期入口和星标；日期支持今天、明天、原生选择和清除。状态仅在编辑时展示（看板列预设状态在创建时仍有文字提示）。笔记 ⌘↵ 保存，AI 为次级操作。高频日期选择和键盘操作不添加动画。

## 统一操作控件（2026-09-09）

- 普通操作统一使用 `QuietButtonStyle`：13pt regular 字体、28pt 最小高度、6pt 圆角，悬停浅底色、按下即时加深、禁用降低透明度，不添加过渡动画。
- 图标操作使用 `ActionIcon` + `QuietButtonStyle(icon: true)`：SF Symbols 13pt regular，28×28pt 命中区域，不叠加文字按钮内边距。
- 主操作使用同一按钮的 `prominent: true`，只通过强调色区分；不混用系统 bordered / borderedProminent。
- 菜单统一 `actionMenuStyle()`，共用悬停表面，保留原生菜单、键盘和辅助功能行为。
- 对话入口统一 bubble.left；发送统一 arrow.up，避免额外圆形底座与其他按钮混用。
- 日期格、原生日期选择器、复选框、状态选择器保留对应选择语义，不作为普通操作按钮重绘。

验证：46 项测试，1 项跳过、零失败；release 构建通过。隔离数据库下原生点击加号打开任务编辑器，并检查日期、重要、取消与保存的渲染。深色与完整键盘巡检未在本轮重跑。

# Codenotch 液态玻璃贴边对照 · 2026-09-13

本次只调整 macOS 贴边部分。依据已安装的 `/Applications/Codenotch.app` 及源仓库 `bd62f44`，不再沿用此前自定义的胶囊和灰色卡片。

## 已替换的差异

| 原实现 | 本次实现 | 原版依据 |
| --- | --- | --- |
| 自加黑色把手、细线和描边 | 玻璃模式收起和展开均采用原版当前的玻璃绘制结果 | 实际运行的原版收起态；NotchRootView 的玻璃分支 |
| 对小轮廓直接 glassEffect | 先生成面板大小的 Rectangle 系统玻璃，再裁剪 SideNotchShape | NotchRootView.notch |
| 设置一直显示圆按钮 | 与轮廓同心的四分之一玻璃弧；悬停转为圆盘与图标 | SettingsOrb / MoveHandle / ArcBand |
| 无移动弧线 | 新增移动弧线，按住拖动选择最近的物理屏幕边缘 | MoveHandle 的交互意图；命中在 NSPanel 处理 |
| 独立普通材质卡和三角形 | TooltipTail 曲线与圆角卡片合并为一个 TooltipSilhouette，再应用系统玻璃 | TooltipCard.swift |
| 自定尺寸与稀疏布局 | 使用设计帧比例 44/117，再按 Small 的 0.8 缩放；环、间距、曲率和弧线一致 | Design / NotchLayout / NotchSize |
| 横向直接套竖向尺寸 | 横向按圆环宽度计算间距，增加容纳下方文字的深度 | NotchLayout.cellAlong / bodyDepth |
| 帧与屏幕边缘可能出现细缝 | 根据 NSHostingView 实际尺寸定位，并向边框外溢出 2pt 后裁掉 | NotchRootView.bezelBleed |

提示卡沿目标移动，内容仍为 Noto 的待办和录入说明。原版的账号列表数量与 Noto 的两项功能不同，因此可见主体总长度不会相同。右侧位置保留 Noto 当前偏好，原版仍在左侧。

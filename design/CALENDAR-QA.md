# 任务月历验收记录

后续轻量化版本见 [轻量化交互验收](LIGHTWEIGHT-QA.md)，其布局与交互说明覆盖本文旧版对应部分。

2026-09-09，macOS 原生 SwiftUI / AppKit。实现已落地；**原生拖放端到端验收仍未通过，不能视作整体验收完成。**

## 实现

- 单图标原生菜单：笔记 / 看板 / 日历，原生勾选、⌘1 / ⌘2 / ⌘3、提示及辅助功能名称；旧 `tasks` 偏好对应看板。
- 本地日期月历，七列六行、周一起始、短月截断、今天与邻月日期、最多三条摘要和剩余数量。
- 当天完整列表、未安排收纳盒、已完成任务保留截止日期；全部查询与重要筛选、搜索共享结果。
- 内容宽度 980pt 起右侧详情为 300pt；620pt 窗口保持七列，详情在下方，选中日期时滚到详情，切月及返回今天回到月历。
- 新建使用选中日期或未安排；草稿保留字段，复用编辑、冲突保护、撤销和外部刷新。
- 看板与月历统一 AppKit 拖拽源和接收器。只接受应用内部 `app.noto.task` 数据及原始记录快照；看板只改状态，月历只改日期。取消清除目标高亮，目标高亮不重建 SwiftUI 子视图。
- 未增加数据库字段、依赖、CLI 命令。README、Agent 提示词及 Noto Skill 说明日期与月历的对应关系。保留原工作区图标和构建脚本改动。

## 原生窗口已观察到的结果

测试使用独立 SQLite；未使用个人数据库。

| 场景 | 结果 |
| --- | --- |
| 图标菜单 | 名称、图标、当前勾选和三个快捷键可见；菜单切到看板，⌘1 / ⌘3 切换笔记 / 日历 |
| 选中日期新建 | 选中 9 月 11 日，⌘N 显示该日期、普通、待开始；⌘↵ 保存后日期格与列表出现新记录 |
| 草稿保护 | 输入未保存文字后 ⌘2 被阻止，保留浮层文字并显示提示；Esc 取消 |
| 未安排新建 | 收纳盒中新建的截止日期默认未勾选 |
| 窄窗口与完整列表 | 620pt 深色七列没有横向裁切；＋N 滚到当天完整列表，定位图标返回月历 |
| 未安排已完成记录 | 收纳盒及列表包含没有日期的已完成任务，显示勾选与较淡文字 |
| CLI 自动刷新 | CLI 将已完成任务从 9 日移到 14 日，月历自动更新两格计数，仍显示完成勾选 |
| GUI 清除日期与撤销 | 编辑器取消截止日期、⌘↵ 后收纳盒从 2 变 3；数据库 due 为 NULL，status / completedAt 不变。⌘⇧Z 恢复 14 日 |
| 组合筛选 | 搜索「没有日期」并开启重要筛选后，总数与收纳盒数都为 0，提供清除入口 |
| 当天大量任务 | 单日 28 条（其中 22 条已完成），格内数量和当天标题一致，滚到尾部可访问第 28 条，没有 20 条截断 |
| 浅色与长文字 | 宽屏月历与右侧 300pt 列表；窄格摘要省略，编辑器展示完整文字 |

## 尚未通过的必需验收

- 自动化在看板跨列、月历跨日的实际拖放尝试中未观察到数据库写入。调试时目标接收器可收到 draggingEntered，但没有收到 performDragOperation；原生会话以 operation 0 结束，最终屏幕坐标与合成拖动目标不一致。这提示自动化事件投递可能有限制，但不足以证明实际鼠标拖放正确。
- 因此，**看板跨列、日历跨日、未安排拖入与拖回、取消 / 无效目标 / 原位置、拖放撤销、拖动期间 CLI 并发修改，原生端到端均保持待验收**。部分更新、冲突与撤销的模型测试通过不替代这些结果。
- 已请求在隔离窗口实际拖动「整理月历交互」从 9 月 9 日到 11 日，等待鼠标操作后继续读取 UI 和数据库。只有两者均更新，才可标记通过。
- 中文文字输入、marked-text 防误提交测试已有覆盖；真实拼音候选窗和完整 VoiceOver 键盘巡检尚未完成。没有调用真实 AI provider，本次 AI 修改为提示词说明。
